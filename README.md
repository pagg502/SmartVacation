# Smart Vacation - Under Construction
Transforming a traditional package-based booking platform into an AI-powered travel orchestration system. <br>
Instead of manually filtering limited options, users simply express their travel intent. Our AI layer dynamically<br>
gathers preferences, validates optimal dates through weather intelligence, estimates flights and accommodations,<br>
and composes a personalized travel plan — all within a single conversational flow.

This upgrade demonstrates how legacy ecommerce infrastructure can evolve into an autonomous, intent-driven <br>
booking experience without rebuilding the entire system.

# Requirements:
- Create environment variables with a valid NOVA_API_KEY. (NovaApiService.java/.apiKey(System.getenv("NOVA_API_KEY")))
